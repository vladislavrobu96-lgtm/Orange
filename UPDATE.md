## Самый простой способ с Mac

1. Распакуйте архив. Откройте папку Messages.
2. Откройте ссылку «Загрузка файлов» выше и войдите в GitHub.
3. Перетащите содержимое папки Messages целиком: файлы index.html, styles.css, app.js, sw.js, manifest.webmanifest, README.md, UPDATE.md и папку assets. Саму внешнюю папку Messages загружать не нужно: index.html должен остаться в корне репозитория.
4. Внизу страницы напишите Update Messages design, выберите Commit directly to the main branch и нажмите Commit changes.
5. Дождитесь завершения публикации во вкладке Actions. Затем откройте приложение по прежней ссылке. При необходимости закройте его полностью и откройте повторно: первая загрузка обновляет прежний сервис-воркер.
6. Для новой иконки на iPhone удалите старый ярлык с домашнего экрана и добавьте сайт через Safari → Поделиться → На экран «Домой». Не очищайте данные сайта, если хотите сохранить переписки.

## Что изменено

Аватарка расположена над номером. Убраны подписи «Троллейбусы» и «Автобусы». Все аватарки серые, на основе второго изображения. Использована иконка с первого изображения. Серые и зелёные сообщения, тонкие разделители, плавающие кнопки и поиск снизу. Убраны цветная заливка выбранного чата на телефоне и подсветка касания. Обводка для навигации клавиатурой сохранена серой. Поддерживаются многострочный ввод, светлая/тёмная темы, экранная клавиатура и прежняя история браузера.

В настройках можно выключить декоративный остров. Настоящим Dynamic Island сайт управлять не может. Когда Safari сообщает верхнюю безопасную область, декоративный остров скрывается, чтобы не дублировать системную область экрана.

Функции переписок и локального управления доступом сохранены. Подключения к серверу Base44 в этих исходных файлах нет. Эта сборка самостоятельно не добавляет серверную авторизацию. Приложение не подключено к транспортному оператору; сообщения формируются локально и не являются подтверждением оплаты проезда.


## Активация одним из 20 ключей

После обновления при первом входе появляется запрос № 01–20. Номер выбирается случайно и не меняется после перезагрузки. Откройте свой отдельный файл Messages_Owner_Keys.txt и введите ключ с этим номером. Только соответствующий ключ открывает приложение. Ключи содержат пять латинских букв и цифр, регистр букв не важен.

Файл Messages_Owner_Keys.txt сохраните только у себя. На GitHub загружайте только папку сайта из архива. Таблица с ключами в архив сайта не включена.

После активации доступ сохраняется в этом браузере, включая работу без интернета после первой успешной загрузки сайта. В другом браузере или после очистки данных понадобится активация заново. Повторение номера у разных людей возможно; один ключ может использоваться повторно для своего номера. Ключи бессрочные, удалённого отзыва нет. Вход в панель администратора не снимает экран активации.

Установленная старая версия тоже запросит ключ один раз после этого обновления. История сообщений сохранится. Локальная проверка не является защитой от изменения исходного кода или данных браузера.
