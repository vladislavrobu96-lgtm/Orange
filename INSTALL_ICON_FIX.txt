КАК ОБНОВИТЬ ГИТХАБ
1. Откройте репозиторий https://github.com/vladislavrobu96-lgtm/Orange
2. Скачайте ZIP репозитория или откройте локальную копию проекта.
3. Скопируйте из этого пакета файлы и папку assets ПОВЕРХ файлов проекта, подтвердив замену одноимённых файлов.
4. Сохраните/закоммитьте изменённые файлы в GitHub. Остальные файлы не меняйте.
5. Дождитесь публикации GitHub Pages. На Android/iOS при необходимости удалите только ярлык с домашнего экрана и добавьте его снова. Не очищайте данные сайта, если важно сохранить историю и активацию.

Примечание: ZIP нельзя просто загрузить в корень GitHub вместо распаковки.
При открытии архива убедитесь, что файлы лежат в корне проекта (manifest.webmanifest, sw.js, assets/...); не в дополнительной вложенной папке.
